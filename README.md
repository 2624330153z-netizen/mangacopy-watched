# 拷贝漫画「看过屏蔽」说明书

在漫画列表里给看过的漫画做标记，并可以一键隐藏。

## 安装

1. 浏览器装 **Tampermonkey**（油猴）扩展。
2. 点油猴图标 → **新建脚本**。
3. 把 `mangacopy-watched.user.js` 的内容全部粘进去，按 Ctrl+S 保存。
4. 打开 https://www.mangacopy.com/comics ，**左下角出现控制栏**就是装好了。

## 怎么用

**书封面右上角的「看过」按钮**

- 没看过：红字白底「看过」。
- 看过了：白字红底「看过」。再点一下可取消。

**页面左下角的控制栏**

| 按钮 | 作用 |
| --- | --- |
| 已看过: N 部 | 显示已标记数量 |
| 隐藏看过 / 显示全部 | 一键隐藏看过或显示所有漫画 |
| 导出 | 备份记录到文件 |
| 导入 | 从文件恢复（可选覆盖或追加） |
| 清除记录 | 清空全部记录，慎用 |

## 小技巧

- 按 **←** 上一页，按 **→** 下一页。
- 翻页后会自动跳到「排序」那一行，不用往下拉。

## 注意

- 记录存在浏览器本地。换浏览器、清缓存、无痕模式关闭都会丢。
- 建议偶尔点「导出」备份，换设备时用「导入」恢复。
