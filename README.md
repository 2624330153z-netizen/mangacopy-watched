# 拷贝漫画「看过屏蔽」脚本 使用说明书

## 一、安装

1. 安装浏览器扩展 **Tampermonkey**（油猴）
   - Chrome / Edge：在应用商店搜索 Tampermonkey
   - Firefox：在附加组件搜索 Tampermonkey
   - 官网：[https://www.tampermonkey.net/](https://www.tampermonkey.net/)

2. 打开 Tampermonkey 控制面板，点击 **新建脚本**（+号图标）

3. 清空编辑器默认内容，将 `mangacopy-watched.user.js` 的全部代码粘贴进去

4. 按 **Ctrl+S** 保存

5. 访问 [拷贝漫画发现页](https://www.mangacopy.com/comics?ordering=-popular)，右上角出现控制栏即安装成功

---

## 二、控制栏按钮

页面**右上角**会有一个固定的控制栏，包含：

| 按钮                        | 功能                                         |
| --------------------------- | -------------------------------------------- |
| 已看过: N 部                | 显示当前已标记的漫画数量                     |
| **隐藏看过** / **显示全部** | 切换是否隐藏已标记的漫画（隐藏后直接不显示） |
| **导出**                    | 下载 JSON 备份文件                           |
| **导入**                    | 从 JSON 备份文件恢复数据                     |
| **清除记录**                | 清空所有标记数据                             |

### 漫画卡上的操作

- 每个漫画封面右上角有 **「看过」** 按钮
- 点击 → 封面模糊 + 显示「已看」标签，按钮变为红色 **「✓ 看过」**
- 再次点击 → 取消标记，恢复原样

---

## 三、三种显示状态

| 状态                  | 效果                                            |
| --------------------- | ----------------------------------------------- |
| **未标记**            | 正常显示，按钮为白色「看过」                    |
| **已标记，未隐藏**    | 封面模糊 + 红色「已看」覆层，按钮红色「✓ 看过」 |
| **已标记 + 开启隐藏** | 该漫画卡片直接不显示（display: none）           |

---

## 四、数据存储

- 数据存储在浏览器 localStorage 中
- 记录的是漫画 URL 中的唯一标识符（path_word），如 `woduzishenji`
- 翻页、刷新、关闭浏览器均不会丢失

### 数据丢失的情况

| 操作                      | 是否丢失             |
| ------------------------- | -------------------- |
| 点击「清除记录」          | 是                   |
| 清除浏览器网站数据/Cookie | 是                   |
| 无痕/隐私模式关闭窗口     | 是                   |
| 更换浏览器或设备          | 是（新浏览器无数据） |
| 卸载 Tampermonkey         | 数据仍在但不再生效   |

**建议定期点击「导出」备份数据。**

---

## 五、导入/导出

### 导出

点击「导出」→ 浏览器下载 `mangacopy-watched-日期.json` 文件  
内容示例：

```json
[
  "woduzishenji",
  "dianjuren",
  "jiandieguojiajia"
]
```

### 导入

点击「导入」→ 选择之前导出的 JSON 文件 → 弹出三选一弹窗：

| 按钮             | 功能                         |
| ---------------- | ---------------------------- |
| **覆盖**（红色） | 以导入文件为准，清空现有记录 |
| **追加**（绿色） | 合并到现有记录，不删已有数据 |
| **取消**（灰色） | 不进行操作，关闭弹窗         |

导入成功后自动刷新页面。
