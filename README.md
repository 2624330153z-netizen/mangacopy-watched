# 拷贝漫画「看过屏蔽」说明书

在漫画列表里给看过的漫画做标记，并可以一键隐藏。

## 安装

1. 浏览器装 **Tampermonkey**（油猴）扩展。
2. 点油猴图标 → **新建脚本**。
3. 把 `mangacopy-watched.user.js` 的内容全部粘进去，按 Ctrl+S 保存。
4. 打开 https://www.mangacopy.com/comics ，**左下角出现控制栏**就是装好了。

## 怎么用

**书封面右上角的「看过」按钮**

- 没看过：红字白底「看过」。
- 看过了：白字红底「看过」。再点一下可取消。

**漫画详情页**

打开某本漫画后，在「开始阅读 / 加入书架 / 分享」那一行也有「看过」按钮，可以直接标记，回到列表会同步生效。

**作者页**

打开作者的「相关作品」页（`/author/xxx/comics`）时，每本书封面右上角同样有「看过」按钮，隐藏/显示、翻页都和列表页一致。

**搜索结果页**

站内搜索（`/search?q=...`）的结果里，每本书封面右上角也有「看过」按钮。这个页面翻页是局部刷新的，所以按 ← → 翻页后会自动滚回结果标题处。

搜索翻页**不做限速**，想翻多快都行。如果翻得太密、被站点接口限流（429），页面底部会弹出红色提示「接口限流了，稍等几秒再翻页」，几秒后自动消失，不会再有 `undefined` 对话框。

**页面左下角的控制栏**

| 按钮 | 作用 |
| --- | --- |
| 已看过: N 部 | 显示已标记数量 |
| 隐藏看过 / 显示全部 | 一键隐藏看过或显示所有漫画 |
| 导出 | 备份记录到文件 |
| 导入 | 从文件恢复（可选覆盖或追加） |
| 清除记录 | 清空全部记录，慎用 |

## 小技巧

- 按 **←** 上一页，按 **→** 下一页。
- 翻页后会自动跳到「排序」那一行（作者页跳到作品列表开头，搜索页跳到结果标题），不用往下拉。

## 注意

- 记录存在浏览器本地。换浏览器、清缓存、无痕模式关闭都会丢。
- 建议偶尔点「导出」备份，换设备时用「导入」恢复。
- 搜索页翻页不限速。被站点接口限流时，页面底部会弹一条红色提示，等几秒再翻即可。
- 控制栏右下角显示当前脚本版本，例如 `← → 翻页 · v2.15`，可用来确认装的是不是最新版。
